# Plan: vision (fog of war, sight cone, shared team sight, centre scan) (2026-09-30)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development, under workflow v1.3
> (`C:\UniStuff\Y3\MinorSkilled\Resources\core\`): one brief file per task, one sonnet implementer under the Editor lock,
> one read-only **opus** review per task (vision is shared between players, so every task counts as networking), fixes
> re-reviewed, the controller's own check, logged, one commit per task, push after the review's fixes land.

**Goal (play terms):** you only see enemies inside your team's sight (a cone toward each teammate's cursor plus a circle
around them, blocked by walls); everything else lies under a dim fog; the minimap shows the fog and red dots for enemies
your team sees; gun sounds carry a direction and fade with distance; the team holding the centre sends a red sonar wave
every 30 s that marks every enemy it passes.

**Architecture:** each client works out its own team's sight from what it already has (positions, facing, team, alive).
Pure rules in plain C# (`Assets/scripts/Vision/Rules/`, edit-mode tested); one owner-only service on the local player
(`TeamSight`) answers "can my team see this point?" for everything else; a top-down sight texture drives a full-screen
fog pass and the minimap fog. No RPC changes; one new Player Property (`vScp`).

**Tech stack:** Unity 6000.0.70f1, URP (Forward+), Photon PUN 2, NUnit edit-mode tests.

**Spec:** `docs/superpowers/specs/2026-09-30-vision-design.md`. **Mockups + Tudor's picks:**

### Task 1: Sight rules + VisionConfig (D6, D7, D8, D9, A4, A8)
- **Create** `VisionConfig` (menu `OverPower/Vision Config`, `[Header]` groups "Fog", "Sight", "Zones", "Centre scan",
  "Minimap", a full-sentence `[Tooltip]` per field, `[Range]`/`[Min]`): `fogEnabled`, `fogColour`, `fogDarkness`,
  `coneAngleDegrees`, `coneLength`, `circleRadius`, `eyeHeight`, `wallRevealDepth`, `lineSampleSpacing`,
  `sightRayCount`, `sightTextureSize`, `zoneOwnersVisibleWithoutSight`, `minimapEnemyColour`, `scanIntervalSeconds`,
  `scanWaveSpeed`, `scanWaveColour`, `scanDotSeconds`, `scanTiers` (four bools, I-IV). Defaults from the spec. The asset
  written with every field as YAML lines, grepped.
- **Create** `VisionRules` (static, `Overpower.Vision`):
  ```csharp
  public readonly struct SightShape { public readonly float ConeAngleDegrees, ConeLength, CircleRadius; }
  public static SightShape ShapeFor(float angle, float length, float radius, bool scoped,
                                    float scopedAngle, float scopedLength, float scopedCircleChange);
  public static bool InShape(Vector2 eye, Vector2 facing, SightShape shape, Vector2 point);   // no walls
  public enum ViewerMode { Alive, Dead, Spectating }
  public static bool IsEye(int localTeam, ViewerMode mode, int watchedTeam, int candidateTeam, bool candidateAlive,
                           bool candidateIsLocal);
  public static bool TeamSees(IReadOnlyList<Eye> eyes, Vector2 point, Func<Vector2, Vector2, bool> clearLine);
  ```
  (`Eye` = position, facing, shape.) Circle radius never goes below 0.
- **Tests first** (`VisionRulesTests`): a point straight ahead inside the length is seen, beyond it is not; a point just
  outside the half-angle is not, just inside is; a point behind within the circle is seen, behind outside it is not;
  the scoped shape is narrower and longer than the normal one and its circle smaller (compared to the unscoped shape
  built from the same config, never to numbers); a blocked line hides a point in the cone; a dead local player's eyes
  are its living teammates and not itself; spectating uses the watched team; team unknown → only the local player;
  enemies and dead teammates are never eyes. See each fail first.
- **Check:** tests only (no scene change). **Review:** opus.

### Task 3a: The sight shape and texture (A3)
- **Create** `SightPolygon` (pure): given an eye, a shape, `sightRayCount` and a raycast function, returns the polygon
  (fan of points) with each hit pushed `wallRevealDepth` into the wall; the circle part as a fan too.
- `TeamSight` draws every eye's polygon into a single-channel `RenderTexture` (`sightTextureSize`) covering the arena's
  world extent (reuse `MinimapConfig`'s world extent), white = seen; published as a global shader texture + its
  world-to-texture transform.
- **Tests first** (`SightPolygonTests`): with no walls the polygon's far points lie at the cone length; a wall in front
  cuts the rays at the wall plus the reveal depth; the circle part covers behind the eye; ray count sets the points.
- **Check:** one client: the texture saved to a PNG from Play Mode and looked at (a cone cut by a wall). **Review:** opus.

### Task 3b: The fog on screen (D8, D10 look 1A + 2A) - 2 clients
- **Create** `FogRenderFeature` (URP `ScriptableRendererFeature`, after opaques/transparents, before UI) with
  `Fog.shader`: rebuilds each pixel's world position from depth, samples the sight texture at its XZ, outside → blend
  toward `fogColour` by `fogDarkness`, hard edge. Turn **Depth Texture on** in `PC_RPAsset`; add the feature to
  `PC_Renderer`. `fogEnabled` off → the pass does nothing.
- **Check (2 clients):** captures from both at the same moment: walls cutting the fog, the fog over a wall top, a
  teammate's cone lit on the other client, the HUD and world-space names never fogged. Frame time before/after noted
  from the Profiler or `get_performance_stats`. **Review:** opus (plus a rendering sanity read).

## Risks

- **Task 3b (the fog pass)** is the riskiest: a URP renderer feature and the depth texture. Fallback if it can't be
  made right in two rounds: fog as a darkening decal-like mesh on the ground only (wall tops unfogged) - logged for Tudor.
- **Hidden-but-networked players:** hiding renderers must not disable colliders, `PlayerNetSync` or labels' logic.
- **Many effect call sites** (Task 4-5): a missed one leaks an enemy's position; the Task 12 check lists every effect.
- **Performance:** ~3 eyes × `sightRayCount` rays a frame + the pass; measured in Task 3b.

## Out of scope

Anti-cheat; last-known positions; a hit-direction arc; making other sounds fog-aware.
